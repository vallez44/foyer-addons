# Foyer

Tableau de bord mural pour iPad, servi par un add-on Home Assistant.

- 10 cadrans : Photos, Maison Modulaire Plus, Analogique, Maison Modulaire, Flux, Modulaire, Météo,
  Calendrier, Horloge, Caméras.
- Tuiles en verre dépoli sur fond satiné, une touche par appareil, pages détaillées, Centre de contrôle ;
  tuiles à disposer directement sur l'écran.
- Réglages dans l'écran, comme ceux de l'iPad ; Apps (Musique sur les HomePod, Rappels, Minuteurs, Horloge
  mondiale, nouvel événement d'agenda) et raccourcis vers les apps d'Apple.
- Température et humidité des HomePod, via une automatisation de l'app Maison d'Apple.
- Dans la barre latérale de Home Assistant, ou en plein écran sur l'écran d'accueil de l'iPad
  (port direct 8110 avec appairage par code). Fonctionne aussi sur tablette Android (Chrome, Fully Kiosk).
- Sans application à installer ; JavaScript ES5 pour les anciens iPad.
- Rien ne sort de chez vous.

Voir l'onglet **Documentation** pour l'installation et l'utilisation.
